## Decided
- Clean rewrite as upadrian/adel-waf (MIT, PHP ^8.0, namespace AdelWAF\, src/ PSR-4); WordPress, CI4 and single-file versions removed (legacy kept in tag v1.0.1).
- Anomaly scoring (threshold 5) over normalized inputs; rules live in rules/default/*.json, generated by tools/build-default-pack.php (edit rules there, then rerun it to refresh sha256s in manifest.json).
- Storage: Redis (ext-redis/Predis) -> FileStorage fallback, 30s circuit breaker; bans are `ban:{ip}` JSON keys (contract for the external admin tool). Default mode is monitor; bootstrap fails open.
- Signed rule updates (ed25519 via sodium) + sha256 + regex compile/ReDoS probe, atomic `current` pointer file (no symlinks, for shared hosting).

## Tried and ruled out
- Substring rules from v1 (href=, http://, count( ...) caused false positives; replaced by regex + scoring.
- bans.jsonl file export from the original plan: dropped; CLI `--json` and Redis keys cover it.

## Watch out
- Old .gitignore ignored `bin/`; replaced it.
- In tests, `$defaults + $cfg` order matters: `$cfg + defaults` so overrides win.
- PCRE JIT ignores backtrack_limit; RulesUpdater disables pcre.jit during ReDoS probes.
- Local php lacks ext-sodium: run tests with `php -d extension=sodium vendor/bin/phpunit`. PHPStan needs --memory-limit=1G.
- Don't run `python` heredocs in Git Bash here (hangs).
